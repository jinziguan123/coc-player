# CoC 7 版规则覆盖矩阵

> 本文回答一个问题：**哪些规则由引擎确定性结算，哪些由 AI/KP 裁量，哪些尚未实现。**
> 对外介绍本作时请引用本表，不要使用「完整实现 CoC 七版」这种表述。
>
> 口径：`server/app/rules/coc/` 与 `server/app/services/` 中的确定性代码；AI 提示词只负责
> 语义裁量，不能作为「已实现规则」的证据。

## 确定性实现（引擎/服务直接结算）

| 领域 | 已实现内容 | 主要位置 |
|---|---|---|
| 属性 | 8 项属性骰法（3d6×5、2d6+6×5）、幸运 3d6×5、15–19 岁两次取高 | `rules/coc/character.py` |
| 年龄 | 各年龄档体能/APP 减值、EDU 增强检定、教育上限 99、未成年修正 | `rules/coc/character.py` |
| 派生值 | HP / MP / SAN / MOV（含年龄减值）/ 伤害加值 / 体格 / 闪避 / 母语 | 同上 |
| 建卡 | 技能点预算、信用评级上限、职业列表 112 个、装备 52 件、武器 106 件 | `rules/coc/occupations.py` 等 |
| 技能检定 | 普通 / 困难 / 极难难度，大成功、极难、困难、大失败边界，奖励/惩罚骰 | `rules/coc/checks.py` |
| 对抗检定 | 双方等级比较，贯穿与战斗对抗路径共用 | `rules/coc/checks.py` |
| 理智 | SAN 检定、固定/骰式损失、单次损失 ≥1/5 触发临时疯狂、SAN 归零永久疯狂 | `rules/coc/checks.py`、`turn_effects.py` |
| 疯狂发作 | 10 种「一阵疯狂」症状、症状惩罚域、失能接管、持续回合、到期解除 | `rules/coc/madness.py` |
| 战斗 | 先攻（火器优先）、命中/闪避/反击、伤害/DB、贯穿、连射、抵近、掩体、视线、夹击、重伤/濒死/昏迷/死亡 | `rules/coc/combat.py`、`combat_service.py` |
| 治疗 | 急救稳定伤势/回复 1 点、医学 1d3、每处伤一次急救 | `combat.py`、`first_aid` 相关服务 |
| 追逐 | 距离轨、移动对抗、速度差奖惩、障碍、脱身/追上判定 | `rules/coc/chase.py` |
| 成长 | 幕间技能成长检定（成功技能才可成长） | `engine.py`、`growth_service.py` |
| 财富 | 信用评级 → 消费水平/现金/资产换算 | `character.py` |

## 由 AI/KP 裁量（有规则指引，但状态不是引擎强制）

| 规则 | 现状 |
|---|---|
| 孤注一掷（Pushing） | KP 提示词允许并说明后果加重；无独立重掷工具/UI，无确定性状态记录 |
| 花费幸运 | KP 提示词允许按差额补成普通成功；无引擎扣幸运、无 UI 入口 |
| 检定是否触发、难度与奖惩骰 | 由 TurnPlanner 裁定后经确定性检定函数结算 |
| SAN 损失规格 | 模组场景事件中的 `san_loss` 会被确定性执行；未写明的由 KP 判断 |
| 战斗/追逐何时开始 | 由 KP 调用 `start_combat` / `start_chase` 工具；开始后的轮次结算确定 |
| 神话生物的怪物能力 | 以 NPC 数值卡 + 通用战斗规则近似，不建模逐项特殊能力 |

## 明确未实现

- 不定性疯狂（indefinite insanity）的完整触发、症状与恢复周期（当前只有状态枚举，没有结算流程）。
- 魔法、咒文、仪式、附魔物品与克苏鲁神话技能成长。
- 官方追逐规则中的完整障碍表、行动选项与车辆追逐。
- 火器故障/卡壳细则、自动武器的完整散布规则。
- 灵异/理智恢复、精神分析深度治疗等长期恢复系统。
- 完整 DnD 规则引擎（仅数据类型与模组字段兼容）。

## 变更纪律

- 把上表任何「AI 裁量 / 未实现」条目改成确定性实现时，必须同时：
  1. 更新本表；
  2. 在 `server/app/rules/coc/` 或对应服务补纯函数与单测；
  3. 若涉及前端交互，在 `apps/web/src` 补组件测试。
